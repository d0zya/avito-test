# Поиск объявлений услуг

Для каждого из 2452 поисковых запросов нужно выбрать до 50 объявлений из корпуса `benchmark_items.parquet` (189 212 объявлений). Качество измеряется средним по запросам Recall@50. Формат данных и ответа описан в [TZ.md](TZ.md), анализ данных — в [ноутбуке](notebooks/01_eda.ipynb).

## Решение

Итоговый вариант — одноэтапный поиск по тексту объявления с приоритетом точного совпадения локации. Для текста используются два TF-IDF индекса:

- словные униграммы и биграммы по заголовку, параметрам и началу описания;
- символьные n-граммы 3–5 по заголовку, чтобы учитывать варианты написания.

Сходство считается как `0.7 × word + 0.3 × char`. Если `search_location_id == item_location_id`, оно умножается на `13` (вес бонуса `12`). Затем выбираются 50 объявлений с наибольшим сходством. Фильтр запроса включен в словное представление. Метки положительных пар используются для выбора веса локации и локальной оценки, но не для обучения TF-IDF индексов.

Для проверки использовались 1000 разных текстов запросов и все 344 825 уникальных объявлений из train. Доля запросов с пустым фильтром в holdout — 63%, как в benchmark. Вес 12 проверен также на втором holdout из 1000 других текстов запросов. Корпус benchmark меньше train-каталога, поэтому абсолютные локальные и leaderboard-значения отличаются.

| Вариант | Локальный Recall@50 | Leaderboard Recall@50 |
| --- | ---: | ---: |
| E01: текст + слабый бонус локации | 0.408855 | 0.427991 |
| E02: раздельный учет поисковой фразы и фильтра | 0.428113 | не отправлялся |
| E06: бонус локации 4 | 0.651121 | 0.677459 |
| E07: бонус локации 12 | 0.677821 / 0.669608¹ | ≈0.700² |

¹ Первый и второй непересекающиеся holdout. ² Результат leaderboard сообщен округленно как `0.7`; точное значение неизвестно.

Проверяли и dense-поиск с [multilingual-e5-base](https://huggingface.co/intfloat/multilingual-e5-base): zero-shot Recall@50 `0.528835`, после дообучения на 20 000 положительных парах `0.567939`. Адаптация вектора запроса по первым найденным объявлениям дала `0.560915`. Эти три оценки получены на отдельном подкаталоге из 50 000 объявлений; на нем E01 давал `0.623014`. Dense-варианты не отправлялись на leaderboard. Их результаты приведены для полноты исследования, код этих пробных запусков не входит в опубликованное решение. Подробности и ограничения сравнения — в [журнале экспериментов](experiments/experiment_log.md).

## Воспроизведение

Положить три Parquet-файла в `data/NLP_avito_interns-dataset/`, затем из корня проекта выполнить:

```bash
python -m pip install -r requirements.txt
python experiments/e07_location_sweep.py --make-submission
```

Скрипт повторяет локальную проверку, затем записывает `submissions/submission_03.csv` и `answer.csv`. Выходной CSV содержит два столбца, `query_id` и `answer`, без индекса; в каждом ответе ровно 50 различных `item_id` из benchmark-корпуса. Данные, веса encoder и промежуточные эмбеддинги в репозиторий не входят.
